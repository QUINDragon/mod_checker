ModChecker AutoFix - 自动修复模块
====================================

本目录包含 ModChecker 的自动修复和补丁生成功能。
This directory contains ModChecker's auto-fix and patch generation features.

---

目录结构 / Directory Structure
-------------------------------

  __init__.py          模块入口 / Module entry
  patch_generator.py   生成兼容补丁包 / Generate compatibility patches
  backup.py            备份管理 / Backup management
  manifest_fixer.py   轻度问题自动修复 / Minor issue auto-fix
  README.txt           本文件 / This file

---

兼容补丁包说明 / About Generated Patches
------------------------------------------

ModChecker 能够自动检测 MOD 之间的冲突（如两个 MOD 修改了同一个资源文件），
并为用户生成 Content Patcher 格式的兼容补丁包。

ModChecker can detect conflicts between mods (e.g., two mods modifying the same
asset), and generate Content Patcher compatible patch packs to resolve them.

生成的补丁包存放在:
Generated patches are stored in:
  mod_check/patches/
